How long should a password be?

For important accounts such as email and banking, use at least 16 characters. Length matters more than anything else: each extra character multiplies the number of guesses an attacker needs. Use a different password for every account, and turn on two-factor sign-in where you can.

How Nullen makes passwords

Every character is picked independently using your browser's secure random number generator. If you select several character types, the password always includes at least one of each. The page runs entirely on your device, with no account, no cookies and no ads.

Is an online password generator safe?

It can be, if it runs in your browser and sends nothing. Nullen does both: your password is made on your device and never sent anywhere. You can check by going offline after the page loads. It keeps working.

What does "bits of entropy" mean?

It measures how many guesses an attacker would need. Every extra bit doubles the work. Nullen calls under 50 bits weak, 70 and up strong, and 100 and up very strong.

Should I use a password manager?

Yes. A manager remembers a different long password for every account, so you only have to remember one. Generate a password here, save it in your manager, and never reuse it elsewhere.
